### Non-Breaking

- The shipped `config.json` and the configuration examples in `README.md` now use the
  current tracing configuration keys: `Options` instead of `TraceOptions`, and
  `MetricsPrefix` instead of `TraceOptionMetricsPrefix`. Both spellings are accepted by
  the tracing library in use today, so existing configuration files keep working; this
  only moves the shipped example to the form that will still be accepted once the
  legacy key names are dropped.
