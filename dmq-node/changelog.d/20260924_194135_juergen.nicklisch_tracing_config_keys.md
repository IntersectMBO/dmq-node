### Non-Breaking

- The shipped `config.json` and the configuration examples in `README.md` use the
  current tracing configuration keys: `Options` instead of `TraceOptions`, and
  `MetricsPrefix` instead of `TraceOptionMetricsPrefix`. Either layout is accepted
  as a whole, so existing configuration files keep working, but rename both keys
  together (see the `hermod-tracing` entry below). This moves the shipped example
  to the form that will still be accepted once the deprecated names are dropped.
